# Security

Bouncer can quit other apps and eject drives, so please tell me about anything that could let it be misused, such as a way to stop processes it shouldn't or to tamper with its updates.

To report a problem privately, [open a security advisory](../../security/advisories/new). Please don't use a public issue. I'll reply as soon as I can.

Fixes go into the latest version only. Bouncer checks for updates by itself and asks before installing them.
